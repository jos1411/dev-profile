## 🏗️ Project Architecture

This is a **static-first Astro v5 site** with:

- **Zero client-side JavaScript** (except one React island for the terminal typewriter)
- **Bilingual support** (Spanish/English) with i18n routing
- **Dark/Light theme toggle** with localStorage persistence
- **Tailwind CSS v4** for styling
- **SEO optimized** with JSON-LD, Open Graph, and Twitter Cards
- **Accessibility-first** design (WCAG 2.1 AA compliant)

### Sections

1. **Hero** — Introduction with animated terminal typewriter
2. **About** — 7 core strengths covering full-stack expertise

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/jos1411/dev-profile.git
cd dev-profile

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:4321/` to see the site.

### Build for Production

```bash
npm run build
```

The static site will be generated in the `dist/` folder.

## 🌐 Deployment

This site is designed to be deployed on:

- **Vercel** (recommended)
- **Netlify**
- **GitHub Pages**
- Any static hosting service

### Environment Variables

Before deploying, replace `{domain}` in `src/layouts/BaseLayout.astro` with your actual domain:

```javascript
const domain = 'yourdomain.com'; // e.g., 'josemonge.dev'
```
